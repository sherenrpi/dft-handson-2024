# dft-handson-2024
Jupyter Notebooks from the Hands-On DFT Sessions – Fall 2024

This repository contains Jupyter Notebooks from the Hands-On Density Functional Theory (DFT) sessions conducted as part of Prof. Meunier’s Fall 2024 DFT course at Penn State. 
The notebooks focus on practical applications of DFT using GPAW and ASE (Atomic Simulation Environment), covering key computational techniques, workflows, and electronic structure calculations.

These materials provide hands-on experience for students and researchers interested in leveraging GPAW and ASE for DFT simulations.
